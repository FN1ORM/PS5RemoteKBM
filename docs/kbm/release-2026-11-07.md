# November 7 update

The owner reports successful cross-city PS5 PIN registration and real gameplay
using the Android Tailscale subnet router. Registration is now proved on that
setup. It does not establish that the separate PSN traversal path works.

## Changes

- Home page: compact navigation, clearer connection labels, console cards and
  consistent dark colors. Keyboard/mouse, connection tools and the manual are
  directly accessible.
- Shared message shell: maximum width/height follow the live viewport, titles and
  bodies wrap, long messages scroll. Token/registration logs and console PIN
  dialogs use the bounded shell. Registration/manual forms scroll and use one
  column when narrow. Dialog headers reserve space for navigation and actions.
- PSN failures stay readable until dismissed and explain the working VPN fallback.
  Cancelling an attempt remains separate from a connection failure.
- F4: optional PS5 quality presets apply to BOTH local and remote video settings,
  because routed private IPs can select local settings. Presets are 720p30/5 Mbps,
  720p60/8 Mbps and 1080p60/15 Mbps, H.264 SDR. They take effect on reconnection.
- F4 diagnostics: use the installed Tailscale CLI without a shell to list peers
  and run bounded, asynchronous direct/relay peer pings. They do not change VPN
  settings. Outputs stay in the local panel and are not uploaded.
- F2: optional precise mouse preset with an advancing 8 ms window, linear response
  and no added recenter tail. It preserves sensitivity/bindings. Existing profiles
  default to their previous behavior; smooth sampling remains available.
- F3: standalone offline HTML manual, with Markdown source, table of contents,
  responsive layout and print styles. No external assets or scripts are needed.
- `--connection-tools` opens diagnostics without the graphics renderer.
- Rest/disconnect choices now explain that Rest Mode ends streaming.

## What this update does not establish

The app cannot replace the phone's routing role with saved pairing credentials,
guarantee traversal through unsupported NAT, eliminate ISP/Wi-Fi packet loss,
continue gameplay in Rest Mode or disable the PS5's HDMI output. The manual explains
the supported alternatives and practical monitor power/input controls.

Precise input remains controller-stick emulation; game turn limits and response
curves remain in effect. The owner must compare it in their games. No gameplay
latency improvement is claimed from automated tests alone.

## Verification

Seven CTest suites pass: upstream protocol, native input, Windows credentials,
input profiles, responsive dialogs, credential-error redaction and AV initialization.
New tests check advancing mouse-window reversals, stop behavior, micro movement,
neutral release, profile persistence and long-message scrolling while resizing an
open dialog through 1280×720, 800×600, 480×360 and 1024×768 viewports.

The packaged main window was launched and its registered VPN and PSN entries
visually inspected during development. A direct launch from the build folder lacked
Qt's deployment plugins; the packaged folder supplied them correctly. Further
desktop inspection was stopped by the physical Escape key. Final theme changes
and new native panels have build/automated checks, with final visual/gameplay
acceptance still needed.

Tailscale's local status query reported `NoState` during this work, so no current
VPN RTT, direct/relay classification, stream loss or end-to-end latency was measured.
No fresh PSN or VPN gameplay session was started by the assistant.

The final deployed executable matches the build by SHA-256. Static inspection of
195 x64 PE modules found zero missing dependencies/format errors. The Material-style
headless dialog test also checks repeated confirmation acceptance/rejection and
focus-transfer state. Final CTest run: 7/7 passed in 2.43 seconds (test runtime, not
streaming latency).
